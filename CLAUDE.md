# CLAUDE.md — Telegram Mini App: каталог услуг косметолога

## Что это за проект

Telegram Mini App для частного косметолога-фрилансера. Визуальный каталог услуг + онлайн-запись в 3–4 шага. Целевая аудитория — один специалист, не салон.

## Цель

Дать косметологу инструмент, который выглядит так же ухоженно, как её работы: витрина услуг с фото, простая запись, автоматические напоминания через Telegram.

## Стек (планируемый)

- **Frontend:** React + TypeScript, Vite
- **Telegram SDK:** `@twa-dev/sdk` (обёртка над `window.Telegram.WebApp`)
- **Backend:** Node.js / Python (TBD), хранение данных в БД (TBD)
- **Bot:** `python-telegram-bot` или `aiogram` (TBD)

## Ключевые технические правила

- Всегда вызывать `WebApp.expand()` при старте
- Навигация «Назад» — только через `WebApp.BackButton`, не своя стрелка
- Главное действие — через `WebApp.MainButton`
- Цвета — только через `WebApp.themeParams`, не фиксированные значения
- Отступы — учитывать `--tg-safe-area-inset-bottom`
- Не использовать горизонтальные карусели (конфликт с iOS-жестом закрытия)
- Загрузка < 2 секунд, скелетон-экраны вместо спиннеров
- `HapticFeedback` при нажатиях и успешных действиях

## Экраны (MVP)

1. Каталог услуг — карточки с фото, ценой, длительностью
2. Карточка услуги — описание, фото до/после, кнопка «Записаться»
3. Выбор даты и времени — только свободные слоты
4. Подтверждение — итог записи
5. Экран успеха — анимация + автосообщение в чат

## Экраны (желательно)
