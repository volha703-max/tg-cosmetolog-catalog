## Фаза 1 — Прототип UI (следующий шаг)

**Цель:** кликабельный прототип всех обязательных экранов MVP.

- [ ] Выбрать дизайн-подход (Figma / сразу в коде)
- [ ] Определить цветовую палитру и типографику
- [ ] Спроектировать 5 экранов MVP (каталог → карточка → дата → подтверждение → успех)
- [ ] Проверить путь пользователя: ≤ 4 шага до записи

## Фаза 2 — Frontend (React Mini App)

**Цель:** работающее приложение в Telegram без бэкенда (моковые данные).

- [ ] Инициализировать проект: `npm create vite@latest` + React + TypeScript
- [ ] Установить `@twa-dev/sdk`
- [ ] Настроить `WebApp.expand()` при старте
- [ ] Реализовать `BackButton` и `MainButton`
- [ ] Реализовать адаптацию к теме (`themeParams`)
- [ ] Реализовать safe area отступы
- [ ] Собрать 5 экранов MVP на моковых данных
- [ ] Скелетон-экраны при загрузке
- [ ] `HapticFeedback` при нажатиях

---

## Фаза 3 — Backend + Bot

**Цель:** реальные данные, работающая запись, напоминания.

- [ ] Выбрать стек бэкенда (Node.js / Python)
- [ ] Выбрать БД (PostgreSQL / SQLite / Supabase)
- [ ] API: услуги, слоты, записи
- [ ] Telegram Bot: обработка initData, создание записей
- [ ] Автонапоминания: за 24ч и за 2ч до визита
- [ ] Автосообщение с деталями после успешной записи

## Фаза 4 — Панель мастера

**Цель:** мастер управляет расписанием и услугами без кода.

- [ ] Просмотр предстоящих записей

- [ ] Управление услугами (добавить, изменить цену, скрыть)
- [ ] Список клиентов
