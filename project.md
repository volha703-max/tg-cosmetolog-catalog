# project.md — Контекст и решения

## Проблема, которую решаем

Частный косметолог ведёт клиентов через Telegram-канал, но запись — вручную в личку или через сторонние ссылки. Это создаёт трение: клиент уходит с платформы, мастер тратит время на переписку.

**Незакрытая ниша:** готового красивого Mini App для косметолога-одиночки практически нет. Все конкуренты либо заточены под салоны, либо уродливы, либо избыточны по функционалу.

## Целевой пользователь

- Частный косметолог / мастер бьюти (не салон)
- Ведёт Telegram-канал с контентом
- Хочет упростить запись без администратора
- Не хочет платить дорогую подписку за лишние функции

## Конкурентный анализ (краткий)

| Продукт | Сильная сторона | Слабая сторона |
|---|---|---|
| ALOY | Stories внутри бота | Для салонов, нет демо |
| Beauty-Bot | Мультиканальный вход, низкая цена | Только текстовые кнопки, нет витрины |
| UDS | Лояльность + аналитика | Дорого, без кастомизации дизайна |
| Beauty-App | Геймификация, авто-дни рождения | Избыточно для одного мастера |
| Timepong | Повторяющиеся события | Заточен под групповые форматы |

## Наше главное преимущество

Красивый, быстрый Mini App, который выглядит как авторский бренд мастера, а не корпоративный шаблон. Запуск самостоятельно за 1 день.

## Оптимальная связка

```
Telegram-канал (контент + доверие)
    → Mini App (витрина услуг + запись)
        → Бот (напоминания + подтверждения)
```

## Ключевые решения

- **Путь до записи:** не более 4 экранов (каждый лишний шаг = потеря конверсии)
- **Авторизация:** не нужна — клиент уже в Telegram
- **Напоминания:** через бота (за 24ч и за 2ч до визита)
- **Тема:** адаптация к светлой/тёмной теме Telegram автоматически

## Метрики успеха (MVP)

- Клиент записывается за ≤ 4 шага
- Загрузка < 2 секунд
- Автосообщение с деталями записи после подтверждения
- 0 ручных действий мастера при обработке записи
